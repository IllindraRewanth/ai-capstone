# AI Capstone

## Overview

This repository is my AI Capstone project: **AI Development Environment Setup**, a project that demonstrates setting up a professional AI-assisted software development workflow using Cursor, Git, GitHub, and Node.js.

**Problem:** Developers need a consistent environment for AI-assisted coding and version control.

**Approach:** This project establishes a modern development environment using Cursor AI, Git, GitHub, and Node.js while following best practices such as Conventional Commits and AI-assisted documentation.

## Tech Stack

- Node.js
- Git
- GitHub
- Cursor AI

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)
- [Git](https://git-scm.com/)
- [Cursor](https://cursor.com/)
- A [GitHub](https://github.com/) account

### Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/IllindraRewanth/ai-capstone.git
   cd ai-capstone
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Open the project in Cursor and start developing with AI assistance.
